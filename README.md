## Featured Projects

### KerisKit — Interactive Malay Heritage Learning Platform

A web-based learning platform designed to introduce users to the traditional Malay keris through interactive components and accessible educational content.

**Key Features:**
- Interactive exploration of keris components.
- 360° component image viewing.
- AI-powered chatbot for heritage-related questions.
- REST API integration.
- PostgreSQL database management.

**Technologies:** Java, Spring Boot, PostgreSQL, HTML, CSS, JavaScript, Docker

**Repository:** [KerisKit](https://github.com/Edwolfhard/keriskit-platform)

### NDPP — Malay–English Social Media Text Preprocessing and Normalization Platform

An NLP-based platform designed to preprocess and normalize informal Malay–English social media text, including abbreviations, slang, spelling variations, and code-switching.

**Key Features:**
- Text cleaning and preprocessing.
- Malay–English text normalization.
- Tokenization.
- CSV and TXT file processing.
- Processed data export.
- Word Error Rate (WER) evaluation.

**Technologies:** Python, FastAPI, NLP, HTML, CSS, JavaScript

**Repository:** [NDPP Platform](https://github.com/Edwolfhard/ndpp-platform)


**2. Navigate to the project directory**

```bash

```

**3. Open the website**

Open `index.html` in your preferred web browser.
